# EarForge 耳锻

[English](README.en.md) | 中文

开源、免费、离线可用的练耳训练 Web 应用。目标：做最实用的练耳工具。

## 特点

- **调性听觉优先**：每题先播放终止式建立调性，练的是「在音乐里听出音」，而不只是孤立音程
- **解决到 do**：答完自动播放该音级解决到主音的路径（如 fa→mi→re→do），帮助形成音级的功能感
- **今日训练**：打开就练——按间隔重复自动挑出各模块最需要练的考点，组成一组混合练习，练完给出小结
- **自适应出题**：记录每个考点的掌握度，不熟的多出、久未练的复习；当前级别全部掌握后自动解锁下一级；统计页可一键专练薄弱点
- **多调式**：大调、自然小调、和声小调、多利亚、混合利底亚，各调式进度独立
- **唱出来**：内置 YIN 音高检测，对着麦克风视唱/模唱，实时显示音准偏差（不计八度，男女声都适用）
- **中英双语**：界面支持中文与英文（设置页切换，新用户按浏览器语言）；首调唱名、简谱、固定调唱名、字母音名四种显示方式可切换
- **零门槛**：无需注册，数据存在本机，可导出/导入；PWA 可安装到桌面/手机，断网也能练
- **答错就对比**：答错时自动播放你选的答案，答完后每个选项都能点开试听，「你的答案 / 正确答案」一键对比
- **MIDI 键盘作答**：接上 MIDI 键盘直接弹出答案（调内音级、旋律听写、音程）
- **音色可选**：默认 Web Audio 实时合成（零下载）；可选真实采样钢琴（约 1.4 MB，按需下载后离线可用）

## 练习模块

| 模块 | 内容 |
|---|---|
| 调内音级 | 终止式 + 单音，辨认 do re mi…（含变化音），支持 5 种调式 |
| 级数和弦 | Ⅰ Ⅳ Ⅴ ⅵ…/ ⅰ ⅳ Ⅴ ♭Ⅵ…，单和弦或四和弦进行 |
| 旋律听写 | 3–8 个音的短旋律，按顺序写出唱名 |
| 音程识别 | 上行/下行/和声，附经典歌曲记忆法，6 级 |
| 和弦性质 | 三和弦、挂留、七和弦，可选转位与琶音 |
| 节奏听写 | 预备拍 + 节奏型，从相似的节奏谱中选出听到的那个；从四分音符到切分、三连音 |
| 节奏模仿 | 看谱打或听后打：用空格、触屏或拍手打出节奏，时间轴显示每一下的偏早/偏晚/漏打 |
| 视唱 / 模唱 | 看唱名唱或听后唱，麦克风实时判定 |

## 开发

```bash
npm install
npm run dev      # 开发服务器
npm test         # 单元测试
npm run build    # 生产构建（输出 dist/，可部署到任意静态托管）
```

技术栈：Vite + React + TypeScript，无运行时依赖之外的库。

```
src/
  music/theory.ts      乐理：音程、和弦、调式、唱名体系
  audio/engine.ts      Web Audio 合成音源
  audio/pitch.ts       YIN 音高检测 + 麦克风监听
  engine/progress.ts   掌握度、自适应抽题、自动升级、本地存储
  engine/planner.ts    今日训练选题（间隔重复）、薄弱点
  exercises/*.ts       各练习模块（新增题型只需实现 ExerciseDef）
  i18n/                界面语言：zh.ts 为准，en.ts 同键（类型与测试保证）
  ui/*.tsx             界面
```
